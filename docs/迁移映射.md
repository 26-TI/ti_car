# 迁移映射：`MSPM0_FreeRTOS_BDC_Core` → `MSPM0G3519_CAR`

历史来源：`MSPM0_FreeRTOS_BDC_Core`（迁移时的参考工程，已从本工作区移除，未随本仓库提交）。
迁移方式是**复制**，源工程当时保持原样。

## 1. 代码

| 旧路径（源工程） | 新路径（本工程） | 说明 |
| --- | --- | --- |

## 2. 板级实例名映射（BDC → 本板 SysConfig）

| BDC 宏 | 本工程宏 | 备注 |
| --- | --- | --- |
| `PWMA0_INST` | `PWM_A0_INST` | 引脚全变：BDC PA0/PA1/PA7/PA28 → 本板 PB8/PB12/PA10/PB13 |
| `QEI0_INST`（TIMG9） | `QEI_G9_INST` | 按定时器对齐，不是按序号 |
| `QEI1_INST`（TIMG8） | `QEI_G8_INST` | 同上 |
| `I2C1_INST` / `I2C2_INST` | `I2C_1_INST` / `I2C_2_INST` | 本板另有 `I2C_0_OLED_INST`（实际控制器 I2C0） |
| `UART0/1/3/4_INST` | `UART_0/1/3/4_INST` | 本板另有 `UART_7_INST` |
| `DMA_CH0..3_CHAN_ID` | `DMA_CH0..4_CHAN_ID`（新增） | 本工程 5 路 UART 全开 TX DMA |
| `MCAN0_INST` | `MCAN0_INST` | 唯一同名；本板额外打开了 CAN 中断 |
| `LED_*` `BUZZER_*` `MEN_*` `KEY_*` | **无对应** | 本板 SysConfig 没有这些 GPIO 分组 |

## 3. 目录级变化

| 项 | BDC | 本工程 |
| --- | --- | --- |
| 构建目录 | `build/` | `build/<preset>/` |
| 驱动归属 | `User/Bsp`（工程内） | `Middlewares/M0BSP/code/bsp`（独立仓库 + submodule） |
| 中断入口 | 驱动 `.cpp` 内写死 `UARTx_IRQHandler` | `board_instances.hpp` 清单 + X-macro 展开 |
| 板级配置 | `bsp_cfg.hpp`（含 `extern` 对象） | `User/Board/board_cfg.hpp` + `board_instances.hpp` + `hardware_config.h` |
| 烧录脚本 | `build/<工程名>.elf` 硬编码 | `build/<preset>/<工程名>.elf` + 兜底搜索 |
